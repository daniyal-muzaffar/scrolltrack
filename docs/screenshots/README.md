# Screenshots

Real screenshots are not in the repo yet. Capture them on a phone running the
latest release and save them here with these exact file names (the README links
to them):

- `dashboard.png` — Dashboard tab, with some of today's swipes counted
- `history.png` — History tab
- `life-impact.png` — Life Impact tab
- `settings.png` — Settings tab

Tips: use the dark theme (the default), capture at the phone's native
resolution, and crop the status bar out if it shows personal info.
